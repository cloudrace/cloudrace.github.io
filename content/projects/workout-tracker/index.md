## Workout Tracker (Best Fitness Woburn)

🏋️‍♂️ **Precision 3-Day Full Body Progression & Form Tracking**

Structured specifically for 3 sessions per week (Monday, Wednesday, Friday), this modern web and mobile application balances Upper Body, Lower Body, and Core training in focused 45–60 minute sessions. 

Designed for real gym usage at Best Fitness (Woburn, MA), it features rotating monthly progression plans, 1-click gym machine replacements, verified YouTube form tutorials, in-place set/rep logging, and progress analytics.

### The Tech Stack:
- **Frontend**: Next.js 16 (App Router), React 19, TypeScript
- **Styling**: Tailwind CSS v4 (native dark aesthetic)
- **Mobile & Offline**: Progressive Web App (PWA) & Android Trusted Web Activity (TWA)
- **Backend & Auth**: Firebase Auth, Firestore, and Google Cloud Run
